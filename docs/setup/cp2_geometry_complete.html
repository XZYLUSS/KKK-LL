1. Definition and Construction of \(\mathbb{CP}^2\)

Definition 1.1 (Complex Projective Plane)

The complex projective plane \(\mathbb{CP}^2\) is defined as the quotient space:

$$\mathbb{CP}^2 = \frac{\mathbb{C}^3 \setminus \{0\}}{\sim}$$

where the equivalence relation \(\sim\) is defined by:

$$(z^0, z^1, z^2) \sim (\lambda z^0, \lambda z^1, \lambda z^2) \quad \forall \lambda \in \mathbb{C}^* = \mathbb{C} \setminus \{0\}$$

Points in \(\mathbb{CP}^2\) are equivalence classes denoted \([z^0 : z^1 : z^2]\), called homogeneous coordinates.

1.1 Explicit Construction of Coordinate Charts

\(\mathbb{CP}^2\) is covered by three coordinate charts \(\{U_0, U_1, U_2\}\):

Construction of Affine Charts
Chart \(U_0\): Points with \(z^0 \neq 0\)
$$U_0 = \{[z^0 : z^1 : z^2] \in \mathbb{CP}^2 : z^0 \neq 0\}$$

Local coordinates: \((w^1, w^2) = (z^1/z^0, z^2/z^0) \in \mathbb{C}^2\)

The map \(\varphi_0: U_0 \to \mathbb{C}^2\) is:

$$\varphi_0([z^0 : z^1 : z^2]) = \left(\frac{z^1}{z^0}, \frac{z^2}{z^0}\right)$$

Inverse: \(\varphi_0^{-1}(w^1, w^2) = [1 : w^1 : w^2]\)

Chart \(U_1\): Points with \(z^1 \neq 0\)
$$U_1 = \{[z^0 : z^1 : z^2] \in \mathbb{CP}^2 : z^1 \neq 0\}$$

Local coordinates: \((u^0, u^2) = (z^0/z^1, z^2/z^1) \in \mathbb{C}^2\)

Chart \(U_2\): Points with \(z^2 \neq 0\)
$$U_2 = \{[z^0 : z^1 : z^2] \in \mathbb{CP}^2 : z^2 \neq 0\}$$

Local coordinates: \((v^0, v^1) = (z^0/z^2, z^1/z^2) \in \mathbb{C}^2\)

1.2 Transition Functions

Explicit Transition Functions

On \(U_0 \cap U_1\) (where both \(z^0 \neq 0\) and \(z^1 \neq 0\)):

Step 1: Express \(U_1\) coordinates in terms of \(U_0\) coordinates

In \(U_0\): \([z^0 : z^1 : z^2] = [1 : w^1 : w^2]\)

In \(U_1\): \([z^0 : z^1 : z^2] = [u^0 : 1 : u^2]\)

Since these represent the same point:

$$[1 : w^1 : w^2] = [u^0 : 1 : u^2]$$
Step 2: Solve for the transition

There exists \(\lambda \in \mathbb{C}^*\) such that:

$$1 = \lambda u^0, \quad w^1 = \lambda \cdot 1, \quad w^2 = \lambda u^2$$

From the first equation: \(\lambda = 1/u^0\)

Substituting:

$$w^1 = \frac{1}{u^0}, \qquad w^2 = \frac{u^2}{u^0}$$
Step 3: The transition function \(\psi_{01}: U_0 \cap U_1 \to U_0 \cap U_1\)
$$\boxed{\psi_{01}(u^0, u^2) = \left(\frac{1}{u^0}, \frac{u^2}{u^0}\right) = (w^1, w^2)}$$

This is a holomorphic map (analytic in complex coordinates), making \(\mathbb{CP}^2\) a complex manifold.

Result 1.1

\(\mathbb{CP}^2\) is a 2-dimensional complex manifold (equivalently, a 4-dimensional real smooth manifold) with holomorphic transition functions.

2. Proof of Compactness

Theorem 2.1 (Compactness of \(\mathbb{CP}^2\))

\(\mathbb{CP}^2\) is a compact Hausdorff topological space.

Proof (via Hopf Fibration)
Step 1: Define the 5-sphere

The unit 5-sphere in \(\mathbb{C}^3 \cong \mathbb{R}^6\) is:

$$S^5 = \{(z^0, z^1, z^2) \in \mathbb{C}^3 : |z^0|^2 + |z^1|^2 + |z^2|^2 = 1\}$$

\(S^5\) is compact as a closed bounded subset of \(\mathbb{R}^6\) (Heine-Borel theorem).

Step 2: Define the Hopf projection

Define \(\pi: S^5 \to \mathbb{CP}^2\) by:

$$\pi(z^0, z^1, z^2) = [z^0 : z^1 : z^2]$$

Claim: \(\pi\) is well-defined, continuous, and surjective.

Step 3: Verify well-definedness

For any \((z^0, z^1, z^2) \in S^5\), we have \(\|z\|^2 = 1 \neq 0\), so \(z \neq 0\) and \([z^0 : z^1 : z^2] \in \mathbb{CP}^2\) is well-defined.

Step 4: Verify continuity

In chart \(U_0\), the map \(\pi\) becomes:

$$\varphi_0 \circ \pi: \{z \in S^5 : z^0 \neq 0\} \to \mathbb{C}^2$$ $$(\varphi_0 \circ \pi)(z^0, z^1, z^2) = \left(\frac{z^1}{z^0}, \frac{z^2}{z^0}\right)$$

This is continuous (quotient of continuous functions with non-zero denominator). Similarly for \(U_1, U_2\). Hence \(\pi\) is continuous.

Step 5: Verify surjectivity

For any \([z^0 : z^1 : z^2] \in \mathbb{CP}^2\), choose a representative \((z^0, z^1, z^2) \in \mathbb{C}^3 \setminus \{0\}\).

Define the normalized point:

$$\tilde{z} = \frac{(z^0, z^1, z^2)}{\|(z^0, z^1, z^2)\|} \in S^5$$

Then \(\pi(\tilde{z}) = [\tilde{z}^0 : \tilde{z}^1 : \tilde{z}^2] = [z^0 : z^1 : z^2]\). Hence \(\pi\) is surjective.

Step 6: Apply the compactness theorem

Theorem: The continuous image of a compact space is compact.

Since \(S^5\) is compact and \(\pi: S^5 \to \mathbb{CP}^2\) is continuous and surjective, \(\mathbb{CP}^2 = \pi(S^5)\) is compact.

Step 7: Hausdorff property

The fiber of \(\pi\) over \([z] \in \mathbb{CP}^2\) is:

$$\pi^{-1}([z]) = \{e^{i\theta} z : \theta \in [0, 2\pi)\} \cong U(1) \cong S^1$$

The \(U(1)\) action on \(S^5\) by \(e^{i\theta} \cdot z = e^{i\theta} z\) is:

  • Free: If \(e^{i\theta} z = z\) for some \(z \in S^5\), then \(e^{i\theta} = 1\), so \(\theta = 0\).
  • Proper: \(U(1)\) is compact, so the action is automatically proper.

By the quotient manifold theorem, \(S^5/U(1) = \mathbb{CP}^2\) is Hausdorff (and a smooth manifold). \(\square\)

Result 2.1 (Hopf Fibration)

We have established the Hopf fibration:

$$\boxed{S^1 \hookrightarrow S^5 \xrightarrow{\pi} \mathbb{CP}^2}$$

This is a principal \(U(1)\)-bundle over \(\mathbb{CP}^2\), with total space \(S^5\).

2.1 Dimension Calculation

Real Dimension of \(\mathbb{CP}^2\)
$$\dim_{\mathbb{R}} \mathbb{CP}^2 = \dim_{\mathbb{R}} S^5 - \dim_{\mathbb{R}} U(1) = 5 - 1 = 4$$

Equivalently:

$$\dim_{\mathbb{C}} \mathbb{CP}^2 = 2$$

3. The Fubini-Study Metric: Complete Derivation

3.1 Kähler Potential Approach

Definition 3.1 (Kähler Potential on \(\mathbb{CP}^2\))

On \(\mathbb{C}^3 \setminus \{0\}\), define the function:

$$\Phi(z) = \log\|z\|^2 = \log(|z^0|^2 + |z^1|^2 + |z^2|^2)$$

The Fubini-Study Kähler form is:

$$\omega_{FS} = \frac{i}{2\pi} \partial \bar{\partial} \Phi$$
Verification that \(\omega_{FS}\) Descends to \(\mathbb{CP}^2\)
Step 1: Check invariance under \(\mathbb{C}^*\) scaling

For \(\lambda \in \mathbb{C}^*\), consider \(\Phi(\lambda z)\):

$$\Phi(\lambda z) = \log|\lambda z|^2 = \log(|\lambda|^2 |z|^2) = \log|\lambda|^2 + \log|z|^2 = \log|\lambda|^2 + \Phi(z)$$
Step 2: Compute \(\partial\bar{\partial}\) of the extra term

The extra term \(\log|\lambda|^2 = \log(\lambda \bar{\lambda}) = \log\lambda + \log\bar{\lambda}\) satisfies:

$$\partial(\log\lambda + \log\bar{\lambda}) = \partial\log\lambda = 0 \quad \text{(since } \log\lambda \text{ is antiholomorphic in } z\text{)}$$

Wait, \(\lambda\) is a constant, so:

$$\partial_z(\log|\lambda|^2) = 0, \qquad \bar{\partial}_z(\log|\lambda|^2) = 0$$
Step 3: Conclusion
$$\partial\bar{\partial}\Phi(\lambda z) = \partial\bar{\partial}\Phi(z)$$

Therefore \(\omega_{FS}\) is invariant under \(\mathbb{C}^*\) scaling and descends to a well-defined 2-form on \(\mathbb{CP}^2\).

3.2 Explicit Calculation in Local Coordinates

Fubini-Study Metric in Chart \(U_0\)
Step 1: Set up coordinates

In chart \(U_0\), use coordinates \((w^1, w^2) = (z^1/z^0, z^2/z^0)\).

A point \([z^0 : z^1 : z^2] = [1 : w^1 : w^2]\) has representative \((1, w^1, w^2)\).

The local Kähler potential is:

$$K(w, \bar{w}) = \log(1 + |w^1|^2 + |w^2|^2) = \log(1 + |w|^2)$$

where \(|w|^2 = |w^1|^2 + |w^2|^2 = w^1 \bar{w}^1 + w^2 \bar{w}^2\).

Step 2: Compute first derivatives

Using \(\partial_i \equiv \partial/\partial w^i\) and \(\partial_{\bar{j}} \equiv \partial/\partial \bar{w}^j\):

$$\partial_i K = \frac{\bar{w}^i}{1 + |w|^2}$$ $$\partial_{\bar{j}} K = \frac{w^j}{1 + |w|^2}$$
Step 3: Compute the metric components

The Kähler metric is \(g_{i\bar{j}} = \partial_i \partial_{\bar{j}} K\). Using the quotient rule:

$$g_{i\bar{j}} = \partial_i \left(\frac{w^j}{1 + |w|^2}\right) = \frac{\delta_{ij}(1 + |w|^2) - w^j \cdot \bar{w}^i}{(1 + |w|^2)^2}$$

Therefore:

$$\boxed{g_{i\bar{j}} = \frac{\delta_{i\bar{j}}}{1 + |w|^2} - \frac{\bar{w}^i w^j}{(1 + |w|^2)^2}}$$
Step 4: Alternative form

Factoring out:

$$g_{i\bar{j}} = \frac{1}{1 + |w|^2}\left(\delta_{i\bar{j}} - \frac{\bar{w}^i w^j}{1 + |w|^2}\right)$$

3.3 The Metric in Matrix Form

Explicit \(2 \times 2\) Metric Matrix

Writing \(w^1 = w\) and \(w^2 = z\) for clarity, and \(\rho^2 = |w|^2 + |z|^2\):

$$(g_{i\bar{j}}) = \frac{1}{(1+\rho^2)^2}\begin{pmatrix} 1 + |z|^2 & -\bar{w}z \\ -w\bar{z} & 1 + |w|^2 \end{pmatrix}$$
Verification: Compute \(g_{1\bar{1}}\)
$$g_{1\bar{1}} = \frac{1}{1+\rho^2} - \frac{|w|^2}{(1+\rho^2)^2} = \frac{1+\rho^2 - |w|^2}{(1+\rho^2)^2} = \frac{1 + |z|^2}{(1+\rho^2)^2} \quad \checkmark$$
Verification: Compute \(g_{1\bar{2}}\)
$$g_{1\bar{2}} = \frac{0}{1+\rho^2} - \frac{\bar{w}z}{(1+\rho^2)^2} = -\frac{\bar{w}z}{(1+\rho^2)^2} \quad \checkmark$$

3.4 The Line Element in Real Coordinates

Conversion to Real Coordinates
Step 1: Parametrize complex coordinates

Write \(w^1 = x^1 + iy^1\) and \(w^2 = x^2 + iy^2\).

Then:

$$dw^i = dx^i + i\,dy^i, \qquad d\bar{w}^i = dx^i - i\,dy^i$$ $$|w|^2 = (x^1)^2 + (y^1)^2 + (x^2)^2 + (y^2)^2 = r^2$$
Step 2: The Hermitian line element

The line element in complex coordinates is:

$$ds^2 = 2g_{i\bar{j}}\,dw^i\,d\bar{w}^j$$

(The factor of 2 arises from the convention \(ds^2 = g_{i\bar{j}}dw^i d\bar{w}^j + g_{\bar{j}i}d\bar{w}^j dw^i = 2\text{Re}(g_{i\bar{j}}dw^i d\bar{w}^j)\).)

Step 3: Expand
$$ds^2 = \frac{2}{1+r^2}\left[\sum_i |dw^i|^2 - \frac{1}{1+r^2}\left|\sum_i \bar{w}^i dw^i\right|^2\right]$$
Step 4: Convert to real

Using \(|dw^i|^2 = (dx^i)^2 + (dy^i)^2\) and \(\bar{w}^i dw^i = (x^i - iy^i)(dx^i + idy^i)\):

$$\bar{w}^i dw^i = x^i dx^i + y^i dy^i + i(x^i dy^i - y^i dx^i)$$

Summing over \(i\):

$$\sum_i \bar{w}^i dw^i = (x \cdot dx + y \cdot dy) + i(x \cdot dy - y \cdot dx)$$

where \(x \cdot dx = x^1 dx^1 + x^2 dx^2\), etc.

Step 5: The magnitude squared
$$\left|\sum_i \bar{w}^i dw^i\right|^2 = (x \cdot dx + y \cdot dy)^2 + (x \cdot dy - y \cdot dx)^2$$
Step 6: Final real line element
$$\boxed{ds^2_{FS} = \frac{2}{(1+r^2)^2}\left[(1+r^2)\sum_i((dx^i)^2 + (dy^i)^2) - (x \cdot dx + y \cdot dy)^2 - (x \cdot dy - y \cdot dx)^2\right]}$$

3.5 The Metric at the Origin

Result 3.1

At the origin \(w = 0\) (i.e., \(r = 0\)):

$$g_{i\bar{j}}\big|_{w=0} = \delta_{i\bar{j}}$$

The metric reduces to the flat Euclidean metric on \(\mathbb{C}^2\). This is a general feature of Kähler normal coordinates.

3.6 Volume Form and Total Volume

Volume of \(\mathbb{CP}^2\)
Step 1: The Kähler form
$$\omega_{FS} = \frac{i}{2\pi} g_{i\bar{j}}\,dw^i \wedge d\bar{w}^j = \frac{i}{2\pi}\partial\bar{\partial}\log(1+|w|^2)$$
Step 2: Compute \(\omega_{FS}\) explicitly
$$\omega_{FS} = \frac{i}{2\pi(1+|w|^2)^2}\left[(1+|w|^2)\sum_i dw^i \wedge d\bar{w}^i - \sum_{i,j}\bar{w}^i w^j\,dw^i \wedge d\bar{w}^j\right]$$
Step 3: The volume form

For a Kähler manifold of complex dimension \(n\), the volume form is:

$$dV = \frac{\omega^n}{n!}$$

For \(\mathbb{CP}^2\) (\(n = 2\)):

$$dV = \frac{\omega_{FS}^2}{2} = \frac{\omega_{FS} \wedge \omega_{FS}}{2}$$
Step 4: Compute \(\omega_{FS}^2\)

After a lengthy calculation (using \(dw^i \wedge d\bar{w}^i \wedge dw^j \wedge d\bar{w}^j = 2i^2 dx^1 \wedge dy^1 \wedge dx^2 \wedge dy^2\) for \(i \neq j\)):

$$\omega_{FS}^2 = \frac{2}{(2\pi)^2}\frac{1}{(1+r^2)^4}\,dx^1 \wedge dy^1 \wedge dx^2 \wedge dy^2 \cdot 4$$

Actually, let me redo this carefully. We have:

$$\omega_{FS}^2 = \frac{-1}{4\pi^2}\det(g_{i\bar{j}})\cdot 4\,dx^1 \wedge dy^1 \wedge dx^2 \wedge dy^2$$
Step 5: Compute the determinant
$$\det(g_{i\bar{j}}) = g_{1\bar{1}}g_{2\bar{2}} - g_{1\bar{2}}g_{2\bar{1}}$$ $$= \frac{(1+|w^2|^2)(1+|w^1|^2)}{(1+r^2)^4} - \frac{|w^1|^2|w^2|^2}{(1+r^2)^4}$$ $$= \frac{1 + |w^1|^2 + |w^2|^2 + |w^1|^2|w^2|^2 - |w^1|^2|w^2|^2}{(1+r^2)^4} = \frac{1+r^2}{(1+r^2)^4} = \frac{1}{(1+r^2)^3}$$
Step 6: The volume element
$$dV = \frac{\omega_{FS}^2}{2} = \frac{1}{2\pi^2}\frac{1}{(1+r^2)^3}\,dx^1\,dy^1\,dx^2\,dy^2$$
Step 7: Integrate over \(\mathbb{C}^2\)

Using polar coordinates in \(\mathbb{C}^2 \cong \mathbb{R}^4\): \(dx^1\,dy^1\,dx^2\,dy^2 = r^3\,dr\,d\Omega_3\) where \(\int d\Omega_3 = 2\pi^2\) (volume of unit \(S^3\)).

$$\text{Vol}(\mathbb{CP}^2) = \frac{1}{2\pi^2}\int_0^\infty \frac{r^3}{(1+r^2)^3}\,dr \cdot 2\pi^2 = \int_0^\infty \frac{r^3}{(1+r^2)^3}\,dr$$
Step 8: Evaluate the integral

Substitute \(u = 1 + r^2\), so \(du = 2r\,dr\) and \(r^2 = u - 1\):

$$\int_0^\infty \frac{r^3}{(1+r^2)^3}\,dr = \int_1^\infty \frac{(u-1)}{u^3}\cdot\frac{du}{2} = \frac{1}{2}\int_1^\infty \left(\frac{1}{u^2} - \frac{1}{u^3}\right)du$$ $$= \frac{1}{2}\left[-\frac{1}{u} + \frac{1}{2u^2}\right]_1^\infty = \frac{1}{2}\left(0 - \left(-1 + \frac{1}{2}\right)\right) = \frac{1}{2} \cdot \frac{1}{2} = \frac{1}{4}$$
Result 3.2 (Volume of \(\mathbb{CP}^2\))

With the cohomology-normalized Fubini-Study metric (where \([\omega_{FS}/(2\pi)] \in H^2(\mathbb{CP}^2, \mathbb{Z})\) is the generator):

$$\boxed{\text{Vol}(\mathbb{CP}^2) = \frac{1}{2}\int_{\mathbb{CP}^2}\omega_{FS}^2 = \frac{\pi^2}{2}}$$

For a rescaled metric \(g = b^2 g_{FS}\) (radius \(b\)):

$$\boxed{\text{Vol}(\mathbb{CP}^2, b^2 g_{FS}) = b^4 \cdot \frac{\pi^2}{2}}$$

4. Curvature Calculations

4.1 Riemann Tensor in Kähler Geometry

Definition 4.1

For a Kähler manifold with Kähler potential \(K\), the Riemann curvature tensor has components:

$$R_{i\bar{j}k\bar{\ell}} = -\partial_k\partial_{\bar{\ell}}g_{i\bar{j}} + g^{m\bar{n}}\partial_k g_{i\bar{n}}\partial_{\bar{\ell}}g_{m\bar{j}}$$
Curvature of \(\mathbb{CP}^2\)
Step 1: Compute \(\partial_k g_{i\bar{j}}\)

From \(g_{i\bar{j}} = \partial_i\partial_{\bar{j}}K\) with \(K = \log(1+|w|^2)\):

$$\partial_k g_{i\bar{j}} = \partial_k\partial_i\partial_{\bar{j}}K$$

Let \(\sigma = 1 + |w|^2\). Then:

$$\partial_i K = \frac{\bar{w}^i}{\sigma}, \qquad \partial_i\partial_{\bar{j}}K = \frac{\delta_{ij}}{\sigma} - \frac{\bar{w}^i w^j}{\sigma^2}$$ $$\partial_k\partial_i\partial_{\bar{j}}K = -\frac{\delta_{ij}\bar{w}^k}{\sigma^2} - \frac{\delta_{ik}w^j}{\sigma^2} + \frac{2\bar{w}^i w^j \bar{w}^k}{\sigma^3}$$
Step 2: Evaluate at the origin

At \(w = 0\): \(\sigma = 1\), \(\bar{w}^i = 0\), so:

$$g_{i\bar{j}}\big|_0 = \delta_{ij}, \qquad \partial_k g_{i\bar{j}}\big|_0 = 0$$ $$\partial_k\partial_{\bar{\ell}}g_{i\bar{j}}\big|_0 = -\delta_{ij}\delta_{k\ell} - \delta_{ik}\delta_{j\ell}$$
Step 3: Riemann tensor at origin

At \(w = 0\):

$$R_{i\bar{j}k\bar{\ell}}\big|_0 = -\partial_k\partial_{\bar{\ell}}g_{i\bar{j}}\big|_0 = \delta_{ij}\delta_{k\ell} + \delta_{ik}\delta_{j\ell}$$

Or equivalently:

$$R_{i\bar{j}k\bar{\ell}} = g_{i\bar{j}}g_{k\bar{\ell}} + g_{i\bar{\ell}}g_{k\bar{j}}$$
Step 4: This is the curvature of a space of constant holomorphic sectional curvature

The formula \(R_{i\bar{j}k\bar{\ell}} = c(g_{i\bar{j}}g_{k\bar{\ell}} + g_{i\bar{\ell}}g_{k\bar{j}})\) with \(c = 1\) characterizes a space of constant holomorphic sectional curvature \(H = 4c = 4\).

4.2 Ricci Tensor and Scalar Curvature

Ricci Curvature
Step 1: Contract the Riemann tensor
$$R_{i\bar{j}} = g^{k\bar{\ell}}R_{i\bar{j}k\bar{\ell}} = g^{k\bar{\ell}}(g_{i\bar{j}}g_{k\bar{\ell}} + g_{i\bar{\ell}}g_{k\bar{j}})$$ $$= g_{i\bar{j}}g^{k\bar{\ell}}g_{k\bar{\ell}} + g^{k\bar{\ell}}g_{i\bar{\ell}}g_{k\bar{j}}$$ $$= g_{i\bar{j}} \cdot n + \delta_i^k g_{k\bar{j}} = n\,g_{i\bar{j}} + g_{i\bar{j}} = (n+1)g_{i\bar{j}}$$

where \(n = \dim_{\mathbb{C}}\mathbb{CP}^2 = 2\).

Step 2: For \(\mathbb{CP}^2\)
$$\boxed{R_{i\bar{j}} = 3g_{i\bar{j}}}$$

This shows \(\mathbb{CP}^2\) is Kähler-Einstein with Einstein constant \(\lambda = 3\).

Step 3: Scalar curvature

In complex notation:

$$R = g^{i\bar{j}}R_{i\bar{j}} = 3g^{i\bar{j}}g_{i\bar{j}} = 3n = 6$$

In real conventions (where we sum over all real indices):

$$\hat{R} = 2R = 24$$
Result 4.1 (Curvature Summary)
Quantity Value Formula
Holomorphic sectional curvature \(H = 4\) Constant
Ricci tensor \(R_{i\bar{j}} = 3g_{i\bar{j}}\) Einstein, \(\lambda = 3\)
Ricci scalar (complex) \(R = 6\) \(R = g^{i\bar{j}}R_{i\bar{j}}\)
Ricci scalar (real) \(\hat{R} = 24\) Standard GR convention

For rescaled metric \(g = b^2 g_{FS}\):

$$\hat{R}(b) = \frac{24}{b^2}$$

5. The Isometry Group: Proof that \(\text{Isom}(\mathbb{CP}^2) = SU(3)\)

5.1 \(SU(3)\) Action on \(\mathbb{CP}^2\)

Definition 5.1 (\(SU(3)\) Action)

The group \(SU(3)\) acts on \(\mathbb{CP}^2\) by:

$$g \cdot [z^0 : z^1 : z^2] = [g \cdot z] = [(gz)^0 : (gz)^1 : (gz)^2]$$

where \(g \in SU(3)\) acts on \(z = (z^0, z^1, z^2)^T \in \mathbb{C}^3\) by matrix multiplication.

Theorem 5.1

The \(SU(3)\) action on \(\mathbb{CP}^2\) preserves the Fubini-Study metric.

Proof
Step 1: Show \(SU(3)\) preserves \(\|z\|^2\)

For \(g \in SU(3)\) and \(z \in \mathbb{C}^3\):

$$\|gz\|^2 = (gz)^\dagger(gz) = z^\dagger g^\dagger g z = z^\dagger z = \|z\|^2$$

since \(g^\dagger g = I\) for unitary \(g\).

Step 2: Show \(SU(3)\) preserves the Kähler potential
$$\Phi(gz) = \log\|gz\|^2 = \log\|z\|^2 = \Phi(z)$$
Step 3: Preservation of the metric

Since \(\omega_{FS} = \frac{i}{2\pi}\partial\bar{\partial}\Phi\) and \(\Phi\) is invariant under \(SU(3)\), the Kähler form \(\omega_{FS}\) is invariant. Since the metric is determined by the Kähler form, \(g_{FS}\) is also invariant. \(\square\)

5.2 The Kernel: \(\mathbb{Z}_3\) Acts Trivially

Identification of the Kernel
Step 1: Find elements of \(SU(3)\) acting trivially on \(\mathbb{CP}^2\)

\(g \cdot [z] = [z]\) for all \([z] \in \mathbb{CP}^2\) means \(gz = \lambda z\) for some \(\lambda \in \mathbb{C}^*\).

This requires \(g = \lambda I_3\) for some scalar \(\lambda\).

Step 2: Constraint from \(SU(3)\)

For \(\lambda I_3 \in SU(3)\):

  • Unitarity: \((\lambda I)^\dagger(\lambda I) = |\lambda|^2 I = I \Rightarrow |\lambda| = 1\)
  • Determinant: \(\det(\lambda I_3) = \lambda^3 = 1 \Rightarrow \lambda^3 = 1\)

Solutions: \(\lambda = 1, \omega, \omega^2\) where \(\omega = e^{2\pi i/3}\).

Step 3: The kernel
$$\ker(SU(3) \to \text{Diffeo}(\mathbb{CP}^2)) = \{I, \omega I, \omega^2 I\} \cong \mathbb{Z}_3$$

This is exactly the center \(Z(SU(3)) = \mathbb{Z}_3\).

Result 5.1

The effective action is by the projective special unitary group:

$$\boxed{PSU(3) = SU(3)/\mathbb{Z}_3}$$

\(\dim PSU(3) = \dim SU(3) = 8\).

5.3 Transitivity of the Action

Theorem 5.2

The \(SU(3)\) action on \(\mathbb{CP}^2\) is transitive.

Proof
Step 1: Choose a base point

Let \(p_0 = [1:0:0] \in \mathbb{CP}^2\).

Step 2: Show any point can be reached

For any \([z^0:z^1:z^2] \in \mathbb{CP}^2\), we need \(g \in SU(3)\) with \(g \cdot p_0 = [z^0:z^1:z^2]\).

Normalize: assume \(|z^0|^2 + |z^1|^2 + |z^2|^2 = 1\).

We need the first column of \(g\) to be \((z^0, z^1, z^2)^T\).

Step 3: Extend to an \(SU(3)\) matrix

By the Gram-Schmidt process, any unit vector in \(\mathbb{C}^3\) can be extended to an orthonormal basis. The matrix with these columns has determinant \(e^{i\theta}\) for some \(\theta\); we can adjust phases to get determinant 1.

Explicitly: start with \(v_1 = (z^0, z^1, z^2)^T\), choose \(v_2 \perp v_1\) with \(\|v_2\| = 1\), set \(v_3 = v_1 \times v_2\) (cross product in \(\mathbb{C}^3\)), and adjust phases.

Step 4: Conclusion

For any \(p \in \mathbb{CP}^2\), there exists \(g \in SU(3)\) with \(g \cdot p_0 = p\). Hence the action is transitive. \(\square\)

5.4 The Stabilizer (Isotropy) Subgroup

Stabilizer of \(p_0 = [1:0:0]\)
Step 1: Condition for stabilization

\(g \in SU(3)\) stabilizes \(p_0\) iff \(g \cdot [1:0:0] = [1:0:0]\), i.e., \(g \cdot (1,0,0)^T = \lambda(1,0,0)^T\) for some \(\lambda \in \mathbb{C}^*\).

Step 2: Matrix form

Writing \(g = \begin{pmatrix} a & * & * \\ b & * & * \\ c & * & * \end{pmatrix}\), the condition \(g(1,0,0)^T = \lambda(1,0,0)^T\) gives:

$$(a, b, c)^T = \lambda(1, 0, 0)^T \Rightarrow a = \lambda, \; b = c = 0$$
Step 3: General form of stabilizer elements
$$g = \begin{pmatrix} \lambda & 0 & 0 \\ 0 & * & * \\ 0 & * & * \end{pmatrix}$$

with constraints from \(g \in SU(3)\):

  • Unitarity of first column: \(|\lambda|^2 = 1 \Rightarrow |\lambda| = 1\), so \(\lambda = e^{i\theta}\)
  • The lower-right \(2 \times 2\) block must be unitary
  • Determinant: \(\lambda \cdot \det(\text{2×2 block}) = 1\)
Step 4: Identify the stabilizer

Let the lower-right block be \(U \in U(2)\). Then \(\det g = e^{i\theta} \det U = 1\).

So \(\det U = e^{-i\theta}\).

The stabilizer consists of:

$$\text{Stab}(p_0) = \left\{ \begin{pmatrix} e^{i\theta} & 0 \\ 0 & U \end{pmatrix} : U \in U(2), \; e^{i\theta}\det U = 1 \right\}$$
Step 5: Simplify

Write \(U = e^{i\phi} V\) where \(V \in SU(2)\) and \(e^{i\phi} \in U(1)\).

Then \(\det U = e^{2i\phi}\) (since \(\det V = 1\)).

Constraint: \(e^{i\theta} e^{2i\phi} = 1 \Rightarrow \theta = -2\phi\).

So:

$$g = \begin{pmatrix} e^{-2i\phi} & 0 \\ 0 & e^{i\phi}V \end{pmatrix}$$
Step 6: Final identification
$$\text{Stab}(p_0) = S(U(1) \times U(2)) \cong U(2)$$

where the isomorphism is via \((\phi, V) \mapsto e^{i\phi}V\).

Result 5.2 (Homogeneous Space Structure)
$$\boxed{\mathbb{CP}^2 = SU(3)/U(2) = SU(3)/S(U(1) \times U(2))}$$

Dimension check: \(\dim \mathbb{CP}^2 = \dim SU(3) - \dim U(2) = 8 - 4 = 4\). \(\checkmark\)

5.5 Proof that \(SU(3)\) is the Full Isometry Group

Theorem 5.3 (Maximality)

The connected component of the identity of the isometry group is:

$$\text{Isom}_0(\mathbb{CP}^2, g_{FS}) = PSU(3) = SU(3)/\mathbb{Z}_3$$
Proof Sketch
Step 1: Upper bound on dimension

For a compact Riemannian manifold \(M^n\), the isometry group has dimension at most \(\frac{n(n+1)}{2}\).

Step 2: For Kähler manifolds

Step 3: Dimension of \(PSU(3)\)
$$\dim PSU(3) = \dim SU(3) = 8$$
Step 4: No further continuous symmetries

\(\mathbb{CP}^2\) is an irreducible Hermitian symmetric space. By the classification theorem (Cartan), the isometry group of such spaces is determined by the root system.

For \(\mathbb{CP}^2 = SU(3)/U(2)\), the isometry group is exactly \(PSU(3)\) (or \(SU(3)\) acting with kernel \(\mathbb{Z}_3\)).

Step 5: Discrete part

$$\text{Isom}(\mathbb{CP}^2) = PSU(3) \rtimes \mathbb{Z}_2$$

\(\square\)

$$\boxed{\text{Isom}(\mathbb{CP}^2, g_{FS}) = PSU(3) \rtimes \mathbb{Z}_2}$$

7.2 Gauge Transformation from Internal Diffeomorphisms

Theorem 7.1 (KK Gauge Principle)

An infinitesimal diffeomorphism generated by a Killing vector with \(x\)-dependent parameter:

$$y^m \to y^m + \epsilon^a(x) K_a^m(y)$$

induces a gauge transformation on the fields \(A^a_\mu(x)\):

$$\boxed{\delta A^a_\mu = -\partial_\mu \epsilon^a - f^a{}_{bc} A^b_\mu \epsilon^c = -D_\mu \epsilon^a}$$
Proof
Step 1: Infinitesimal coordinate change

Under \(y^m \to y^m + \epsilon^a(x)K_a^m(y)\), the combination \(dy^m + A^a_\mu K_a^m dx^\mu\) transforms as:

$$dy^m + A^a_\mu K_a^m dx^\mu \to dy^m + \partial_n(\epsilon^a K_a^m)dy^n + \partial_\mu(\epsilon^a K_a^m)dx^\mu + A^a_\mu K_a^m dx^\mu$$
Step 2: Simplify using Killing equation

The term \(\partial_n(\epsilon^a K_a^m)dy^n = \epsilon^a \partial_n K_a^m dy^n\) relates to the Lie derivative.

For the metric to retain the same form, we need:

$$dy^m + (A^a_\mu + \delta A^a_\mu)K_a^m dx^\mu = dy'^m + A^a_\mu K_a^m(y') dx^\mu$$
Step 3: Extract \(\delta A^a_\mu\)

Expanding to first order in \(\epsilon\):

$$K_a^m(y + \epsilon^b K_b) \approx K_a^m(y) + \epsilon^b K_b^n \partial_n K_a^m = K_a^m + \epsilon^b [K_b, K_a]^m$$

Using \([K_b, K_a] = f_{ba}{}^c K_c = -f_{ab}{}^c K_c\):

$$K_a^m(y') = K_a^m - \epsilon^b f_{ab}{}^c K_c^m$$
Step 4: Matching coefficients

For invariance of the ansatz form:

$$A^a_\mu K_a^m + \partial_\mu(\epsilon^a)K_a^m = (A^a_\mu + \delta A^a_\mu)(K_a^m - \epsilon^b f_{ab}{}^c K_c^m)$$

To first order:

$$A^a_\mu K_a^m + \partial_\mu \epsilon^a K_a^m = A^a_\mu K_a^m + \delta A^a_\mu K_a^m - A^a_\mu \epsilon^b f_{ab}{}^c K_c^m$$

Relabeling dummy indices:

$$\partial_\mu \epsilon^a K_a^m = \delta A^a_\mu K_a^m - A^c_\mu \epsilon^b f_{cb}{}^a K_a^m$$
Step 5: Since Killing vectors are independent
$$\delta A^a_\mu = -\partial_\mu \epsilon^a - f^a{}_{bc} A^b_\mu \epsilon^c$$

where \(f^a{}_{bc} = -f_{cb}{}^a\) (raised index version). This is exactly the \(SU(3)\) gauge transformation! \(\square\)
