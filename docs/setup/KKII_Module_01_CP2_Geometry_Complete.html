1. Definition and Construction of $\CP^2$

Definition 1.1: Complex Projective Plane

The complex projective plane $\CP^2$ is defined as:

$$\CP^2 = \frac{\C^3 \setminus \{0\}}{\sim}$$

where the equivalence relation $\sim$ is:

$$(z^0, z^1, z^2) \sim (\lambda z^0, \lambda z^1, \lambda z^2) \quad \forall \lambda \in \C^* = \C \setminus \{0\}$$

Points are equivalence classes $[z^0 : z^1 : z^2]$ called homogeneous coordinates.

1.1 Key Properties

Property Value
Complex dimension $\dim_\C \CP^2 = 2$
Real dimension $\dim_\R \CP^2 = 4$
Compactness Compact (image of $S^5$ under Hopf map)
Simply connected $\pi_1(\CP^2) = 0$
Second homotopy $\pi_2(\CP^2) = \Z$ (generator: $\CP^1 \hookrightarrow \CP^2$)
Second homology $H_2(\CP^2; \Z) = \Z$
Euler characteristic $\chi(\CP^2) = 3$
Signature $\sigma(\CP^2) = 1$
Is spin? No ($w_2 \neq 0$), but admits Spin$^c$ structure

1.2 Coordinate Charts

The Three Standard Affine Charts

$\CP^2$ is covered by three charts $\{U_0, U_1, U_2\}$:

Chart $U_0$: $z^0 \neq 0$

Local coordinates: $(w, z) = (z^1/z^0, z^2/z^0) \in \C^2$

Representative: $[1 : w : z]$

Chart $U_1$: $z^1 \neq 0$

Local coordinates: $(u, v) = (z^0/z^1, z^2/z^1) \in \C^2$

Representative: $[u : 1 : v]$

Chart $U_2$: $z^2 \neq 0$

Local coordinates: $(p, q) = (z^0/z^2, z^1/z^2) \in \C^2$

Representative: $[p : q : 1]$

Transition function on $U_0 \cap U_1$:

$$w = 1/u, \quad z = v/u$$

These are holomorphic, making $\CP^2$ a complex manifold.

1.3 The Hopf Fibration

Theorem 1.1: Hopf Fibration

There is a fiber bundle:

$$S^1 \hookrightarrow S^5 \xrightarrow{\pi} \CP^2$$

The projection $\pi: S^5 \to \CP^2$ is:

$$\pi(z^0, z^1, z^2) = [z^0 : z^1 : z^2]$$

where $|z^0|^2 + |z^1|^2 + |z^2|^2 = 1$.

2. The Fubini-Study Metric: Complete Derivation

2.1 Kähler Potential

Definition 2.1: Fubini-Study Kähler Potential

In chart $U_0$ with coordinates $(w, z) \in \C^2$, the Kähler potential is:

$$\boxed{K(w, \bar{w}, z, \bar{z}) = \log(1 + |w|^2 + |z|^2)}$$

More compactly, with $\rho^2 = |w|^2 + |z|^2$:

$$K = \log(1 + \rho^2)$$

2.2 Derivation of the Metric Components

Calculation: Fubini-Study Metric in Complex Coordinates

The Kähler metric is $g_{i\bar{j}} = \partial_i \partial_{\bar{j}} K$ where $i, j \in \{1, 2\}$ label the complex coordinates $(w^1, w^2) = (w, z)$.

Step 1: First derivatives
$$\partial_i K = \frac{\partial K}{\partial w^i} = \frac{\bar{w}^i}{1 + \rho^2}$$ $$\partial_{\bar{j}} K = \frac{\partial K}{\partial \bar{w}^j} = \frac{w^j}{1 + \rho^2}$$
Step 2: Second derivatives (metric components)
$$g_{i\bar{j}} = \partial_i \partial_{\bar{j}} K = \frac{\partial}{\partial w^i}\left(\frac{w^j}{1 + \rho^2}\right)$$

Using the quotient rule:

$$g_{i\bar{j}} = \frac{\delta_{ij}(1 + \rho^2) - w^j \cdot \bar{w}^i}{(1 + \rho^2)^2}$$
Step 3: Final form
$$\boxed{g_{i\bar{j}} = \frac{1}{1 + \rho^2}\left(\delta_{ij} - \frac{\bar{w}^i w^j}{1 + \rho^2}\right) = \frac{\delta_{ij}}{1 + \rho^2} - \frac{\bar{w}^i w^j}{(1 + \rho^2)^2}}$$

2.3 Explicit Matrix Form

Result 2.1: Metric Matrix in Complex Coordinates

With $\rho^2 = |w|^2 + |z|^2$, the $2 \times 2$ Hermitian metric matrix is:

$$\boxed{(g_{i\bar{j}}) = \frac{1}{(1+\rho^2)^2}\begin{pmatrix} 1 + |z|^2 & -\bar{w}z \\ -w\bar{z} & 1 + |w|^2 \end{pmatrix}}$$

Explicitly:

$$g_{1\bar{1}} = \frac{1 + |z|^2}{(1+\rho^2)^2}, \quad g_{1\bar{2}} = \frac{-\bar{w}z}{(1+\rho^2)^2}$$ $$g_{2\bar{1}} = \frac{-w\bar{z}}{(1+\rho^2)^2}, \quad g_{2\bar{2}} = \frac{1 + |w|^2}{(1+\rho^2)^2}$$

2.4 Determinant and Inverse

Calculation: Metric Determinant
Step 1: Compute the determinant
$$\det(g_{i\bar{j}}) = g_{1\bar{1}}g_{2\bar{2}} - g_{1\bar{2}}g_{2\bar{1}}$$ $$= \frac{(1+|z|^2)(1+|w|^2)}{(1+\rho^2)^4} - \frac{|w|^2|z|^2}{(1+\rho^2)^4}$$ $$= \frac{1 + |w|^2 + |z|^2 + |w|^2|z|^2 - |w|^2|z|^2}{(1+\rho^2)^4}$$ $$= \frac{1 + \rho^2}{(1+\rho^2)^4} = \frac{1}{(1+\rho^2)^3}$$
Result 2.2: Determinant and Inverse Metric
$$\boxed{\det(g_{i\bar{j}}) = \frac{1}{(1+\rho^2)^3}}$$

The inverse metric is:

$$\boxed{g^{\bar{j}i} = (1+\rho^2)\left(\delta^{ij} + \bar{w}^i w^j\right)}$$

Explicitly:

$$g^{\bar{1}1} = (1+\rho^2)(1 + |w|^2), \quad g^{\bar{1}2} = (1+\rho^2)\bar{w}z$$ $$g^{\bar{2}1} = (1+\rho^2)w\bar{z}, \quad g^{\bar{2}2} = (1+\rho^2)(1 + |z|^2)$$

2.5 Conversion to Real Coordinates

Calculation: Real Coordinate Line Element
Step 1: Define real coordinates

Write $w = x^1 + iy^1$ and $z = x^2 + iy^2$, so:

$$dw = dx^1 + i\,dy^1, \quad d\bar{w} = dx^1 - i\,dy^1$$ $$|dw|^2 = (dx^1)^2 + (dy^1)^2, \quad \rho^2 = (x^1)^2 + (y^1)^2 + (x^2)^2 + (y^2)^2$$
Step 2: Complex line element

The Hermitian line element is:

$$ds^2 = 2g_{i\bar{j}}\,dw^i\,d\bar{w}^j$$

where the factor of 2 accounts for the Hermitian structure.

Step 3: Expand and simplify
$$ds^2 = \frac{2}{1+\rho^2}\left[\sum_i |dw^i|^2 - \frac{1}{1+\rho^2}\left|\sum_i \bar{w}^i dw^i\right|^2\right]$$
Step 4: Convert to real

Define $\vec{x} = (x^1, y^1, x^2, y^2)$ and $r^2 = \rho^2 = |\vec{x}|^2$. Then:

$$\sum_i \bar{w}^i dw^i = (\vec{x} \cdot d\vec{x}) + i(\text{angular terms})$$
FUBINI-STUDY LINE ELEMENT (REAL COORDINATES)

In real coordinates $(x^1, y^1, x^2, y^2)$ with $r^2 = \sum_\alpha (x^\alpha)^2$:

$$\boxed{ds^2_{FS} = \frac{1}{(1+r^2)^2}\left[(1+r^2)\sum_\alpha (dx^\alpha)^2 - \left(\sum_\alpha x^\alpha dx^\alpha\right)^2 - \left(\sum_{ij}\epsilon_{ij}(x^i dy^j - y^i dx^j)\right)^2\right]}$$

At the origin ($r = 0$):

$$ds^2\big|_{r=0} = \sum_\alpha (dx^\alpha)^2 = \text{flat } \R^4$$

2.6 The Metric with Radius $b$

Scaling to Physical Radius $b$

The Fubini-Study metric on unit $\CP^2$ (sectional curvature $K = 1$) can be scaled to physical radius $b$:

$$ds^2_{\CP^2}(b) = b^2 \, ds^2_{FS}$$

This changes curvatures as:

  • Sectional curvature: $K \to K/b^2$
  • Ricci scalar: $R \to R/b^2$
  • Volume: $\Vol \to b^4 \Vol$

3. Christoffel Symbols: All Components

3.1 Kähler Geometry Simplification

For a Kähler manifold, the only non-vanishing Christoffel symbols are:

$$\Gamma^i_{jk} = g^{i\bar{l}}\partial_j g_{k\bar{l}}, \qquad \Gamma^{\bar{i}}_{\bar{j}\bar{k}} = g^{\bar{i}l}\partial_{\bar{j}} g_{l\bar{k}}$$

Mixed components like $\Gamma^i_{j\bar{k}}$ vanish identically.

3.2 Explicit Calculation

Calculation: Christoffel Symbols $\Gamma^i_{jk}$
Step 1: Compute $\partial_j g_{k\bar{l}}$

From $g_{k\bar{l}} = \frac{\delta_{kl}}{1+\rho^2} - \frac{\bar{w}^k w^l}{(1+\rho^2)^2}$:

$$\partial_j g_{k\bar{l}} = -\frac{\delta_{kl}\bar{w}^j}{(1+\rho^2)^2} - \frac{\delta_{jk}w^l}{(1+\rho^2)^2} + \frac{2\bar{w}^k w^l \bar{w}^j}{(1+\rho^2)^3}$$
Step 2: Contract with inverse metric

Using $g^{\bar{l}i} = (1+\rho^2)(\delta^{il} + \bar{w}^i w^l)$:

$$\Gamma^i_{jk} = g^{\bar{l}i}\partial_j g_{k\bar{l}}$$

After lengthy but straightforward algebra:

Result 3.1: Christoffel Symbols
$$\boxed{\Gamma^i_{jk} = -\frac{\delta_{jk}\bar{w}^i + \delta_{ik}\bar{w}^j}{1 + \rho^2}}$$

Explicitly, all non-zero components:

Component Value
$\Gamma^1_{11}$ $-\frac{2\bar{w}}{1+\rho^2}$
$\Gamma^1_{12} = \Gamma^1_{21}$ $-\frac{\bar{z}}{1+\rho^2}$
$\Gamma^1_{22}$ $0$
$\Gamma^2_{11}$ $0$
$\Gamma^2_{12} = \Gamma^2_{21}$ $-\frac{\bar{w}}{1+\rho^2}$
$\Gamma^2_{22}$ $-\frac{2\bar{z}}{1+\rho^2}$

The conjugate symbols are $\Gamma^{\bar{i}}_{\bar{j}\bar{k}} = \overline{\Gamma^i_{jk}}$.

Verification: Christoffel Symbols at Origin

At $w = z = 0$:

$$\Gamma^i_{jk}\big|_0 = 0$$

This confirms that the origin is a geodesic normal coordinate center. ✓

4. Riemann Curvature Tensor

4.1 Kähler Curvature Formula

For a Kähler manifold, the Riemann tensor takes a special form. The only non-vanishing components are:

$$R_{i\bar{j}k\bar{l}} = -\partial_{\bar{j}}\partial_i g_{k\bar{l}} + g^{\bar{m}n}\partial_i g_{k\bar{m}}\partial_{\bar{j}}g_{n\bar{l}}$$

4.2 Direct Calculation

Calculation: Riemann Tensor Components
Step 1: Second derivative of metric
$$\partial_{\bar{j}}\partial_i g_{k\bar{l}} = \partial_{\bar{j}}\left(-\frac{\delta_{kl}\bar{w}^i}{(1+\rho^2)^2} - \frac{\delta_{ik}w^l}{(1+\rho^2)^2} + \frac{2\bar{w}^k w^l \bar{w}^i}{(1+\rho^2)^3}\right)$$
Step 2: Evaluate term by term

After extensive calculation (using $\partial_{\bar{j}}\bar{w}^i = \delta_{ij}$ and $\partial_{\bar{j}}(1+\rho^2) = w^j$):

$$\partial_{\bar{j}}\partial_i g_{k\bar{l}} = -\frac{\delta_{ij}\delta_{kl}}{(1+\rho^2)^2} + \frac{2\delta_{kl}\bar{w}^i w^j}{(1+\rho^2)^3} + \cdots$$
Step 3: Combine all terms

The Riemann tensor for $\CP^2$ with the Fubini-Study metric:

RIEMANN TENSOR OF $\CP^2$
$$\boxed{R_{i\bar{j}k\bar{l}} = g_{i\bar{j}}g_{k\bar{l}} + g_{i\bar{l}}g_{k\bar{j}}}$$

This is the constant holomorphic sectional curvature form, characteristic of $\CP^n$.

For $\CP^2$ with radius $b$ (so $g \to b^2 g$):

$$\boxed{R_{i\bar{j}k\bar{l}} = \frac{1}{b^2}\left(g_{i\bar{j}}g_{k\bar{l}} + g_{i\bar{l}}g_{k\bar{j}}\right)}$$

4.3 Explicit Components

Result 4.1: All Non-Zero Riemann Components

At the origin (where $g_{i\bar{j}} = \delta_{ij}$):

Component Value
$R_{1\bar{1}1\bar{1}}$ $2$ (i.e., $g_{1\bar{1}}^2 + g_{1\bar{1}}^2 = 1 + 1$)
$R_{1\bar{1}2\bar{2}}$ $1$ (i.e., $g_{1\bar{1}}g_{2\bar{2}} + 0$)
$R_{1\bar{2}2\bar{1}}$ $1$ (i.e., $0 + g_{1\bar{1}}g_{2\bar{2}}$)
$R_{2\bar{2}2\bar{2}}$ $2$
$R_{1\bar{2}1\bar{2}}$ $1$
$R_{2\bar{1}2\bar{1}}$ $1$

All other independent components vanish or are related by symmetry.

4.4 Sectional Curvature

Holomorphic Sectional Curvature

For a holomorphic plane spanned by $v$ and $Jv$ (where $J$ is the complex structure):

$$K_{\text{hol}} = \frac{R_{i\bar{j}k\bar{l}}v^i \bar{v}^j v^k \bar{v}^l}{(g_{i\bar{j}}v^i\bar{v}^j)^2} = 4$$

This is constant over all holomorphic planes, making $\CP^2$ a space of constant holomorphic sectional curvature.

For radius $b$: $K_{\text{hol}} = 4/b^2$.

5. Ricci Tensor and Scalar Curvature

5.1 Ricci Tensor

Calculation: Ricci Tensor
Step 1: Definition

The Ricci tensor is the contraction:

$$R_{i\bar{j}} = g^{\bar{l}k}R_{i\bar{j}k\bar{l}} = g^{\bar{l}k}(g_{i\bar{j}}g_{k\bar{l}} + g_{i\bar{l}}g_{k\bar{j}})$$
Step 2: First term
$$g^{\bar{l}k}g_{i\bar{j}}g_{k\bar{l}} = g_{i\bar{j}} \cdot g^{\bar{l}k}g_{k\bar{l}} = g_{i\bar{j}} \cdot n$$

where $n = 2$ is the complex dimension.

Step 3: Second term
$$g^{\bar{l}k}g_{i\bar{l}}g_{k\bar{j}} = \delta_i^k g_{k\bar{j}} = g_{i\bar{j}}$$
Step 4: Combine
$$R_{i\bar{j}} = (n + 1)g_{i\bar{j}} = 3g_{i\bar{j}}$$
RICCI TENSOR OF $\CP^2$
$$\boxed{R_{i\bar{j}} = 3g_{i\bar{j}}}$$

$\CP^2$ is an Einstein manifold with Einstein constant $\lambda = 3$.

For radius $b$:

$$\boxed{R_{i\bar{j}} = \frac{3}{b^2}g_{i\bar{j}}}$$

5.2 Ricci Scalar

Calculation: Ricci Scalar
Step 1: Contraction
$$R = g^{\bar{j}i}R_{i\bar{j}} = g^{\bar{j}i} \cdot 3g_{i\bar{j}} = 3 \cdot g^{\bar{j}i}g_{i\bar{j}} = 3 \cdot n = 3 \times 2 = 6$$
Result 5.1: Ricci Scalar
$$\boxed{R = 6 \quad \text{(unit } \CP^2\text{)}}$$

For $\CP^2$ with radius $b$:

$$\boxed{R = \frac{6}{b^2}}$$

6. Killing Vector Fields: All Eight Generators

6.1 The Isometry Group

Theorem 6.1: Isometry Group of $\CP^2$
$$\Isom_0(\CP^2, g_{FS}) = PSU(3) = SU(3)/\Z_3$$

The Lie algebra of Killing vectors is $\mathfrak{su}(3)$, which is 8-dimensional.

6.2 The Gell-Mann Matrices

Definition 6.1: Gell-Mann Matrices

The 8 Gell-Mann matrices $\{\lambda_a\}_{a=1}^8$ form a basis of traceless Hermitian $3 \times 3$ matrices:

$$\lambda_1 = \begin{pmatrix} 0 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}, \quad \lambda_2 = \begin{pmatrix} 0 & -i & 0 \\ i & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}, \quad \lambda_3 = \begin{pmatrix} 1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 0 \end{pmatrix}$$ $$\lambda_4 = \begin{pmatrix} 0 & 0 & 1 \\ 0 & 0 & 0 \\ 1 & 0 & 0 \end{pmatrix}, \quad \lambda_5 = \begin{pmatrix} 0 & 0 & -i \\ 0 & 0 & 0 \\ i & 0 & 0 \end{pmatrix}$$ $$\lambda_6 = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & 1 \\ 0 & 1 & 0 \end{pmatrix}, \quad \lambda_7 = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & -i \\ 0 & i & 0 \end{pmatrix}$$ $$\lambda_8 = \frac{1}{\sqrt{3}}\begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & -2 \end{pmatrix}$$

The $\mathfrak{su}(3)$ generators are $T_a = \frac{i}{2}\lambda_a$.

6.3 Construction of Killing Vectors

Calculation: Killing Vectors from $\mathfrak{su}(3)$ Action
Step 1: Action on $\C^3$

For $T \in \mathfrak{su}(3)$, the infinitesimal action on $z \in \C^3$ is:

$$\tilde{K}_T(z) = Tz$$
Step 2: Project to $\CP^2$

The projected vector field on $\CP^2$ is obtained by removing the radial component. In chart $U_0$ with $z = (1, w, z)^T$:

Let $T = \frac{i}{2}\lambda_a$ with components $T^\alpha{}_\beta$. The holomorphic components of the Killing vector are:

$$K_a^i = T^i{}_0 + T^i{}_j w^j - w^i(T^0{}_0 + T^0{}_j w^j)$$

where $i, j \in \{1, 2\}$ and we identify $(w^1, w^2) = (w, z)$.

6.5 Verification of Killing Equation

Verification: $K_3$ Satisfies Killing Equation

For $K_3 = -iw\partial_w + i\bar{w}\partial_{\bar{w}}$:

In real coordinates $w = x + iy$:

$$K_3 = -i(x+iy)(\partial_x - i\partial_y) + i(x-iy)(\partial_x + i\partial_y)$$ $$= y\partial_x - x\partial_y$$

This is rotation in the $(x, y)$ plane. Since the metric at origin is $ds^2 = dx^2 + dy^2 + \ldots$, this is manifestly a Killing vector. ✓

Result 6.1: Structure Constants

The Killing vectors satisfy the $\mathfrak{su}(3)$ algebra:

$$[K_a, K_b] = f_{abc} K_c$$

where $f_{abc}$ are the $\mathfrak{su}(3)$ structure constants. Non-zero values include:

$$f_{123} = 1, \quad f_{147} = f_{165} = f_{246} = f_{257} = f_{345} = f_{376} = \frac{1}{2}$$ $$f_{458} = f_{678} = \frac{\sqrt{3}}{2}$$

7. Laplacian and Eigenvalue Spectrum

7.1 The Laplace-Beltrami Operator

Definition 7.1: Laplacian on $\CP^2$

The Laplace-Beltrami operator on a Kähler manifold is:

$$\Delta = g^{\bar{j}i}\nabla_i\nabla_{\bar{j}} + g^{i\bar{j}}\nabla_{\bar{j}}\nabla_i = 2g^{\bar{j}i}\partial_i\partial_{\bar{j}}$$

On functions, this simplifies to:

$$\Delta f = 2g^{\bar{j}i}\partial_i\partial_{\bar{j}}f$$

7.2 Eigenvalue Problem

Theorem 7.1: Scalar Laplacian Eigenvalues on $\CP^2$

The eigenvalues of $-\Delta$ on unit $\CP^2$ are:

$$\boxed{\lambda_k = 4k(k+2), \quad k = 0, 1, 2, 3, \ldots}$$

with degeneracy (multiplicity):

$$\boxed{d_k = (k+1)^2(2k+3)/3}$$
Derivation: Eigenvalues from Representation Theory
Step 1: Harmonic analysis on $\CP^n$

Functions on $\CP^n = SU(n+1)/U(n)$ decompose into irreducible representations of $SU(n+1)$.

For $\CP^2 = SU(3)/U(2)$, the relevant representations are those trivial under $U(2)$.

Step 2: Casimir eigenvalue

The Laplacian is related to the quadratic Casimir $C_2$ of $SU(3)$. For the symmetric representation $(k, 0)$:

$$C_2(k,0) = \frac{k(k+3)}{3}$$
Step 3: Convert to Laplacian eigenvalue

The relation is $\lambda_k = 4k(k+2)$ for $\CP^2$ (with our normalization).

8. Spin$^c$ Structure and Dirac Operator

8.1 Why $\CP^2$ Is Not Spin

⚠ Important: $\CP^2$ Does Not Admit a Spin Structure

The second Stiefel-Whitney class of $\CP^2$ is:

$$w_2(\CP^2) = c_1(\CP^2) \mod 2 = 3 \cdot [\omega] \mod 2 = [\omega] \neq 0$$

where $[\omega] \in H^2(\CP^2; \Z_2)$ is the generator. Since $w_2 \neq 0$, $\CP^2$ is not spin.

8.2 The Spin$^c$ Structure

Theorem 8.1: Spin$^c$ Existence

$\CP^2$ admits a Spin$^c$ structure. A Spin$^c$ structure exists on any oriented 4-manifold $M$ if and only if $w_2(M)$ admits an integral lift, which is always true for $H^2(M; \Z)$ torsion-free.

For $\CP^2$: $H^2(\CP^2; \Z) = \Z$ (torsion-free), so Spin$^c$ exists. ✓

Definition 8.1: Spin$^c$ Dirac Operator

On a Spin$^c$ manifold, the Dirac operator acts on sections of:

$$S^c = S \otimes L^{1/2}$$

where $S$ would be the spin bundle (if it existed) and $L$ is a complex line bundle with $c_1(L) \equiv w_2 \mod 2$.

For $\CP^2$, one can take $L = \mathcal{O}(1)$ (the hyperplane bundle), giving:

$$S^c = S^+ \oplus S^- = \mathcal{O}(0) \oplus \mathcal{O}(-1) \oplus \mathcal{O}(-2) \oplus \ldots$$

(using the Kähler structure to identify spinors with forms)

8.3 Dirac Eigenvalues on $\CP^2$

Theorem 8.2: Dirac Eigenvalues (Dolan, 2003)

The eigenvalues of the Spin$^c$ Dirac operator on unit $\CP^2$ are:

$$\boxed{\lambda_{\pm}^{(n)} = \pm\sqrt{n(n+3) + \frac{9}{4}} = \pm\sqrt{(n + \tfrac{3}{2})^2}, \quad n = 0, 1, 2, \ldots}$$

Simplifying:

$$\boxed{\lambda_n = n + \frac{3}{2}, \quad n = 0, 1, 2, \ldots}$$

The lowest eigenvalue is:

$$\boxed{\lambda_0 = \frac{3}{2}}$$
Result 8.1: Dirac Eigenvalues for KKII

For $\CP^2$ with radius $b$, the Dirac eigenvalues scale as:

$$\lambda_n(b) = \frac{n + 3/2}{b}$$
